# Contributing to Aftertime

Thank you for helping build an open planetary balance of matter and energy.

Read [How to participate](docs/en/PARTICIPATE.md) before opening a contribution.
Translations are available in
[Ukrainian](docs/uk/PARTICIPATE.md) and [Russian](docs/ru/PARTICIPATE.md).

## Workflow

1. Search existing Issues and Discussions.
2. Open an Issue for a bounded task or a Discussion for a new direction.
3. Agree on scope before investing in a large implementation.
4. Fork the repository and create a focused branch.
5. Submit a pull request explaining the evidence, assumptions and validation.

Keep commits focused. Add tests or reproducible checks where applicable. Update
all three language versions when changing shared project meaning; if you cannot
translate a change, mark the translations as needing review.

By contributing, you confirm that you have the right to submit the material. Do
not include confidential, restricted, personal or unlawfully obtained data.

The repository license has not yet been selected. Discuss substantial
contributions with maintainers until licensing is resolved.
