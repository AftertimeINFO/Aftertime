# Security and responsible data disclosure

Please do not open a public Issue for vulnerabilities that could expose systems,
personal data, critical infrastructure or sensitive locations.

The project does not yet have a dedicated private security channel. Until one is
published, contact the repository owner privately through an available GitHub
profile contact method and disclose only the minimum information needed to
establish a safe channel.

Do not submit credentials, personal data, confidential commercial information,
restricted infrastructure details or unlawfully obtained datasets to this
repository.
