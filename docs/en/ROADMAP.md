# Roadmap

[Українська](../uk/ROADMAP.md) · [Русский](../ru/ROADMAP.md) · [Home](../../README.md)

The roadmap is organized around verifiable outcomes, not fixed dates.

## Phase 0 — Foundation

- Publish the concept in English, Ukrainian and Russian.
- Agree on mission, scope and terminology.
- Select code, documentation and data licenses.
- Establish contribution, ethics and governance processes.
- Recruit a multidisciplinary founding community.

**Exit condition:** public decisions, maintainers and contribution channels exist.

## Phase 1 — Scientific specification

- Define the material, stock, flow, transformation and energy ontologies.
- Formalize boundaries, units, conservation rules and residuals.
- Define provenance, uncertainty and dispute representation.
- Review the model with relevant domain experts.

**Exit condition:** a versioned specification can describe a real pilot.

## Phase 2 — Auditable pilot

- Select one material, geography and time period.
- Inventory legally usable datasets.
- Build ingestion, normalization and reconciliation tools.
- Publish a traceable opening-to-closing material balance.
- Add a bounded energy balance and uncertainty report.

**Exit condition:** an independent reviewer can reproduce or challenge the result.

## Phase 3 — Open platform

- Build a public data catalog and API.
- Add geospatial and temporal exploration.
- Support competing estimates and scenario analysis.
- Create quality dashboards and automated conservation checks.

**Exit condition:** external teams can add validated datasets and analyses.

## Phase 4 — Network of balances

- Connect multiple materials, transformations and regions.
- Model critical dependencies and recovery pathways.
- Integrate economic data without treating price as physical truth.
- Develop long-horizon scenarios with scientific and public institutions.

**Exit condition:** the system supports decisions at regional and global scale.

## Decisions needed now

1. Which material and region make the best first pilot?
2. Which scientific standards should the ontology reuse?
3. Which open-source and open-data licenses fit the mission?
4. What governance model protects public-interest independence?
5. Which institutions can independently validate the pilot?
