# Как участвовать

[English](../en/PARTICIPATE.md) · [Українська](../uk/PARTICIPATE.md) · [Главная](../../README.ru.md)

Aftertime больше программного проекта. Вклад может быть научным, техническим,
институциональным, финансовым или коммуникационным.

- Исследователи могут проверять предположения, стандарты, уравнения,
  неопределённость и пилоты.
- Инженеры могут работать над онтологиями, происхождением данных, интеграцией,
  сверкой балансов, геосистемами, API, визуализацией и тестированием.
- Владельцы данных могут предоставить законный доступ, метаданные и экспертизу.
- Партнёры и инвесторы могут финансировать конкретные публичные результаты, не
  покупая контроль над научными выводами.
- Авторы, дизайнеры и переводчики могут сделать идею понятной и доступной.

Хорошее первое предложение содержит проблему, её значение для миссии, источники
или экспертизу, ограниченный результат, юридические и этические риски и способ
независимой проверки. Небольшие проверяемые вклады лучше широких обещаний.

Отделяйте измерения от оценок и мнений, ссылайтесь на первичные источники,
указывайте неопределённость, не публикуйте конфиденциальные или незаконно
полученные данные и раскрывайте конфликты интересов.

До создания отдельных каналов используйте GitHub Issues для конкретных задач, а
GitHub Discussions — для идей, партнёрств и научной дискуссии.
