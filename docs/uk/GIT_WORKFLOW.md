# Робота з Git

Основний репозиторій: https://github.com/AftertimeINFO/Aftertime.git.
Він має дві гілки: `main` для інтегрованих змін і `DEV` для розробки.
Використовуйте саме ці назви. Починайте та завершуйте розробку в `DEV`.

```sh
git switch DEV
git pull --ff-only origin DEV
# Реалізуйте й перевірте зміни, закомітьте явно вибрані файли.
git push origin DEV
git switch main
git pull --ff-only origin main
git merge --no-ff DEV
git push origin main
git switch DEV
git merge --ff-only main
git push origin DEV
```

Якщо `main` оновилася незалежно, злийте `origin/main` у `DEV` і перевірте
результат перед інтеграцією. Не переписуйте спільну історію через force-push.
Якщо використовується PR, його напрямок — `DEV` → `main`; після злиття
гілку `DEV` потрібно зберегти.

## Розташування коду

- `platform/` — актуальна система Model Lab, редактор BPMN, сервер і тести.
- `prototype/` — ранній прототип, звичайні відстежувані файли цього репозиторію.
  Його початкова Git-історія збережена комітом об'єднання. Це не submodule;
  окремий Git remote та авторизація не потрібні.
- `prototype/.openai/hosting*.json` — історичні налаштування хостингу, а не
  Git-залежність. Об'єднання Git не змінює та не публікує розміщений сайт.

Рання версія платформи збережена як батьківський коміт злиття; актуальною
залишається поточна реалізація платформи.
