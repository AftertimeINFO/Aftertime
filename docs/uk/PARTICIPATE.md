# Як долучитися

[en](../en/PARTICIPATE.md) · [uk](PARTICIPATE.md) · [home](../../README.uk.md)

Aftertime більший за програмний проєкт. Внесок може бути науковим, технічним,
інституційним, фінансовим або комунікаційним.

- Дослідники можуть перевіряти припущення, стандарти, рівняння, невизначеність і пілоти.
- Інженери можуть працювати над онтологіями, походженням даних, інтеграцією,
  звіркою балансів, геосистемами, API, візуалізацією та тестуванням.
- Власники даних можуть надати законний доступ, метадані та експертизу.
- Партнери й інвестори можуть фінансувати чіткі публічні результати, не купуючи
  контроль над науковими висновками.
- Автори, дизайнери й перекладачі можуть зробити ідею зрозумілою та доступною.

Добра перша пропозиція містить проблему, її значення для місії, джерела або
експертизу, обмежений результат, юридичні та етичні ризики і спосіб незалежної
перевірки. Невеликі перевірювані внески кращі за широкі обіцянки.

Відокремлюйте вимірювання від оцінок і думок, посилайтеся на первинні джерела,
вказуйте невизначеність, не публікуйте конфіденційні чи незаконно отримані дані
та розкривайте конфлікти інтересів.

До створення окремих каналів використовуйте GitHub Issues для конкретних завдань,
а GitHub Discussions — для ідей, партнерств і наукової дискусії.
