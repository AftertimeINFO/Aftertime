# Модель системи

[English](../en/SYSTEM_MODEL.md) · [Русский](../ru/SYSTEM_MODEL.md) · [Головна](../../README.uk.md)

Це початкова гіпотеза, а не завершений стандарт. Вона створена для критики й
уточнення науковцями, інженерами та галузевими фахівцями.

## Основні сутності

| Сутність | Призначення |
| --- | --- |
| Матеріал | Елемент, молекула, речовина, суміш, сировина або продукт |
| Запас | Кількість матеріалу в обмеженому місці та стані |
| Потік | Передача матеріалу між запасами |
| Трансформація | Перетворення входів на продукти, викиди, відходи й тепло |
| Місце | Точка, територія, об’єм, об’єкт, транспорт або юрисдикція |
| Суб’єкт | Людина, організація, держава чи інша контролююча сторона |
| Спостереження | Підтверджене джерелом твердження |
| Передача енергії | Вхід, вихід, зберігання, корисна робота або розсіювання |

Кожний запис має містити матеріал, кількість та одиницю, час, місце, фізичний
стан і концентрацію, власника й форми контролю, джерело, метод, невизначеність,
зв’язки з потоками й трансформаціями та енергетичні показники.

У межах визначеного періоду входи, виходи та зміна запасу мають узгоджуватися з
явно вказаною похибкою. Невідповідність не приховується, а зберігається як
непояснений залишок.

Система має зберігати окремі джерела й суперечливі оцінки, а не створювати одне
число без походження. Перший пілот повинен охопити один важливий матеріал,
обмежену територію та період, кілька етапів переміщення й перетворення, не менш
ніж два незалежні джерела і вимірюваний зв’язок з енергією.
