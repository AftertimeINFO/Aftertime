# Changelog

## 0.4.0-rc.2 — 2026-08-29

- Storm Arwen, 2021 автоматично обирається та запускається після відкриття Model Lab;
- автозапуск очікує завантаження відповідної моделі й часової шкали та не створює дублікати run;
- недоступна черга симуляції повертає retryable `503` замість `Internal Server Error`;
- вибір точки або ряду моніторингу фокусує відповідний вузол схеми;
- release gate явно перевіряє Redis і simulation worker.

## 0.4.0-rc.1 — 2026-08-28

- додано типізовані порти, фізичні середовища та перевірку сумісності зв’язків;
- додано автоматичний каталог observables і контекстне додавання моніторингу;
- додано типізовані події, CEP-правила та незмінний monitor snapshot для run;
- додано створення моделей, draft-копії, редагування та видалення зв’язків;
- порядок виконання відокремлено від координат полотна;
- демонстраційні дані більше не перезаписують користувацькі моделі під час старту;
- додано regression-тести несумісних портів і таймауту API;
- додано release gate та окреме версіонування регламентів.

## 0.3.0 — 2026-08-26

- виправлено частоту для відокремлених електричних островів;
- додано node-level вимірювання напруги, частоти, потужності й навантаження;
- додано контрольні точки ТЕС і споживача;
- додано конфігуровані комплекти графіків із вкладками, лініями та стовпчиками;
- додано вибір об’єкта, параметра й типу ряду та збереження конфігурації в PostgreSQL;
- додано масштаб часу і швидкий фокус «Аварія ±12 год»;
- у Storm Arwen візуалізовано розрив: споживач знеструмлений, ТЕС залишається під напругою.

## 0.2.0 — 2026-08-26

- виправлено запуск симуляцій: worker виконує короткі кроки й більше не блокує чергу одним run;
- додано перетягування поточної позначки часу з checkpoint replay/branch для переходу назад;
- додано незалежні базову та подієву швидкості, presets і довільне значення;
- додано налаштовувані події-тригери та тривалість подієвої швидкості;
- додано окремі списки запрограмованих і фактично виконаних подій;
- журнал виконаних подій сортується від найновіших до найстаріших;
- панель швидкостей отримала явну червону кнопку закриття.
